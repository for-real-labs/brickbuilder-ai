# Generation input attribution

`public.generations` and `public.latest_generations` expose:

| Column | Meaning |
| --- | --- |
| `input_type` | Original input: `text`, `image` (photos included), `glb`, `ldraw`, or `unknown`. |
| `input_format` | Original model file extension (`glb`, `io`, `ldr`, `mpd`), when recorded. |
| `entry_page` | Allowlisted pathname that submitted this revision, including `/image-to-lego`, `/photo-to-lego`, `/glb-to-lego`, and `/use-ai-to-edit-ldraw`. |

Input type and file format follow a model through AI edits and manual revisions. The entry page describes the submitting page for that particular revision. `endpoint` still identifies the processing operation; `mode` still identifies the composer mode.

The server derives input type from the request, rather than trusting a client-supplied type. Entry attribution records no URL query strings, filenames, image data, or prompts. Non-web callers can omit `entry_page`.

Historical rows are backfilled from endpoints and saved input-reference images. Images generated by `textToBricks` do not make the original input an image. Old incomplete AI jobs without a saved reference remain `unknown`. Historical page and LDraw extension attribution cannot be recovered and remain null.

## PostHog

Browser page views include route changes through the configured `history_change` default. `generation_started` is emitted when the landing composer, GLB upload, or LDraw upload receives a generation ID. Its properties include `generation_id`, `page`, and `input_type`; model uploads also include `input_format`. LDraw import acceptance is an import event, not proof of AI generation or completion.

Existing `landing_generate_clicked`, image upload events, and `ldraw_upload_*` events remain. GLB now has `glb_upload_picker_opened`, `glb_file_selected`, `glb_upload_started`, `glb_conversion_completed`, and `glb_conversion_failed` events. Browser delivery depends on normal analytics settings and blockers. Backend PostHog capture is currently disabled; the database is the durable source of generation input attribution.
